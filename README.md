# Win32-Linker
Win32 Linker (linker.exe) - generates PE-executable, capable to emit .exe and .dll and companion lib \
ELF linker (elf_linker.exe) - generates ELF executable file

# Build:
Run build.bat - for Windows \
Run linux_build.bat - for Linux

# Run samples
Run run.bat - for Windows \
In Linux\WSL - run ./linux_hello
